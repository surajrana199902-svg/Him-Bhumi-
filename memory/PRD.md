# Himbhoomi MVP

## Product goal
Create a premium Himachal Pradesh property discovery experience that turns a location search into a property inquiry.

## Current scope
- Full-bleed luxury homepage with location-first discovery
- MongoDB-backed property catalog with automatic starter listings
- Location-filtered responsive property grid
- Property detail experience with gallery, amenities, nearby places, map link, and inquiry form
- Admin workspace for property CRUD and inquiry review

## Deferred until credentials are provided
- Firebase Auth and Firestore
- Google Maps interactive embed/JavaScript SDK
- Persistent binary image/video uploads through object storage
